## What changed
### AI-use compiler: `scripts/ai-usage.mjs`, run with `pnpm ai-usage`
- Reads every `board/done/NN.md` receipt, takes its `## AI-use note` (or `## AI use`) section and writes `AI_USAGE.md`.
- Groups notes by the ticket's `Tracks:` line from any `.scratch/<feature>/issues/` folder (Core, ENS, Hedera, World, or a combination).
- Lists receipts with no AI-use note under "Receipts missing an AI-use note" and names them on stderr.
- Reads both receipt heading styles: `# NN: title (receipt)` and `# Receipt NN: title`.
- `AI_USAGE.md` is regenerated from all current receipts. Ticket 34 re-runs it last.
