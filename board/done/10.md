# 10: Critic registers with a stake (receipt)

## What changed
- `contracts/contracts/CriticRegistry.sol`: `registerCritic(nullifier, expiry, sig)` payable, `requestWithdraw`/`withdraw` (cooldown only), `stakeOf`, `isCritic`, `minStake`, `attestor`. Reverts: `DuplicateNullifier`, `ExpiredVoucher`, `BadSignature`, `SellerCannotCritique`, `StakeTooLow` (plus `AlreadyRegistered`, withdraw errors). ## Spec deviations / notes
- Done-when syntax: with pnpm 9 use `pnpm --filter contracts test -- --grep ...` (same as ticket 08).
- `withdraw` enforces the cooldown only; the "not in an open round" check needs RoundManager (later ticket). `slashStake` wiring via `setRoundManager` is ready but unused here.
- `/critics` items are `{address, nullifier, stake}` (stake = current tinybars, after slashes); the type lives in `apps/api` and `apps/web/lib/api.ts`, not `packages/shared` (frozen).
- Voucher is not bound to the registry address (spec/03 lists only nullifier, critic, expiry, chainid).
- Local attestor key is Hardhat's well-known dev key, used only in the e2e fixture.
