## Research applied

- [CheckList, ACL 2020](https://aclanthology.org/2020.acl-main.442/): behavioral cases can expose failures concealed by aggregate accuracy. The deterministic held-out fixture covers negative length, fractional mass, and temperature conversions, with inspectable cases and exact expectations. These fixtures demonstrate the mechanism, not general service accuracy.
- [Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena](https://arxiv.org/abs/2306.05685): judge biases and limitations motivate retaining outputs and using exact/schema/regex checks wherever possible. The existing configured adapter fixes temperature at zero, and only rubric cases need a model judge; fixed temperature is not a guarantee of truth or reproducibility.
- [Stanford HELM](https://github.com/stanford-crfm/helm), Apache-2.0: inspected its reproducible, transparent evaluation approach. Retained explicit suites, generated cases and outcomes rather than adding a heavy Python evaluation dependency to the existing TypeScript runner.

## Limits and deviations

- The workspace renamed packages to `@skeptique/*`; commands use their real scoped names rather than the ticket's older short filter.
- Deterministic model and plain local service HTTP calls are test fixtures. This test does not claim a live LLM evaluation, sponsor testnet transaction, x402 settlement, or external marketplace integration.
- The default evidence store is in memory and loses evidence on process restart; callers can inject the existing `EvidenceStore` interface. A restart cannot silently fabricate a review: unavailable evidence is omitted.
- The minimal chain source makes two event queries per detail request; a persistent indexer is outside this ticket. Production API deployment configuration is ticket 21, and ENS aggregate-score display is ticket 20.
