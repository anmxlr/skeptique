# 35: Critic runs unattended: watch, review, commit, reveal (receipt)

## What changed
- `apps/critic/src/daemon.ts`: `createCriticDaemon` with `tick()` and `run(signal, pollMs)`. Each tick reveals rounds in their reveal window from saved state (failures are logged and retried next tick until `revealEnd`), then walks open commit-phase rounds oldest first. A round is skipped if already committed (a saved-but-uncommitted state resumes the same score instead of re-reviewing), if the critic's `activeRound` is non-zero, or with less than the margin left before `commitEnd`. The review gets `min(roundBudget, commitEnd - now - margin)` and is raced against that deadline. A throw, a timeout or a finish after `commitEnd` is logged, makes no commit, and the round is not retried (no repeat x402 spend).
- `apps/critic/src/main.ts`: `createCriticFromEnv(env, deps?)` wires the real pieces: manifest (`loadDeployment`), viem chain reader (incremental `RoundOpened` scan from `deploymentBlock`, chain time from the latest block, `CriticRegistry.activeRound`), `createRoundAgent` with `FileRoundStateStore`, `runServiceReview` against `API_URL`, Hedera x402 or local mode, and the OpenAI-compatible probe model from env. `apps/critic/src/cli.ts` is the entry point; `pnpm --filter @skeptique/critic start` runs it (adds `tsx` and `@skeptique/x402-client` to the package).
- `.env.example`: `CRITIC_PRIVATE_KEY`, `CRITIC_ACCOUNT_ID`, `CRITIC_HEDERA_PRIVATE_KEY`, `API_URL`, `CRITIC_STATE_PATH` (required), plus commented optional `X402_MODE`, `CRITIC_POLL_MS`, `CRITIC_ROUND_BUDGET_MS`, `CRITIC_COMMIT_MARGIN_SECS`. The repo `.env` lacks these; `pnpm env:check` will name them.
- Existing `runner`, `probes`, `review`, `round-agent`, `round-chain` are untouched.

## Spec deviations
- The e2e runs the three daemons in one process (`createCriticFromEnv` three times, separate keys, env and state files) rather than as three OS processes: the local chain's chain id differs from the manifest schema's literal 296, so the manifest is injected via `loadDeployment`. They use local x402 mode and a fixed probe model. Not run live against Hedera or an LLM (needs env vars the repo `.env` lacks).
- Unit tests use a fake chain and fake clock (`chain.now`) plus real tiny timers for the deadline race.
- `biome` still reports one warning on a bigint `Math.min` suggestion in `main.ts`; applying it would be wrong (bigint).
