## Spec deviations
The env check is not green. The owner closed the ticket anyway, because every missing value belongs to another ticket:

- **`HCS_TOPIC_ID`, `X402_FACILITATOR_URL`:** chosen by spike 02 (`spec/notes/hedera-x402.md`, not written yet).
- **`ENS_PARENT_NAME`:** chosen by spike 03 (`spec/notes/ens.md`, not written yet).
- **`WORLD_CLIENT_ID`, `WORLD_CLIENT_SECRET`, `WORLD_REDIRECT_URI`:** `.env.example` assumes OIDC credentials, but the World Developer Portal now registers a World ID 4.0 relying party (app_id, rp_id, signing_key). The human stored those values instead. Spike 05 should replace these three keys in `.env.example`.
