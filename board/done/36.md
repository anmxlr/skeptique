# 36: Round keeper finalises rounds and opens re-review rounds

## What changed
- `apps/relayer/src/keeper.ts`: `createKeeper({ client, wallet, roundManager, serviceRegistry, criticRegistry, fromBlock, log })` with `tick()` and `run(pollMs, signal)`.
  - Finalises every round past `revealEnd` that is not finalised (void rounds included, since ticket 25). A settled-rounds cursor means finalised rounds are never resent.
  - Then opens rounds for services with bounty and no open round, never more open at once than `max(1, unlockedRegisteredCritics / kMin)`. Services are taken least-recently-reviewed first, so with 3 critics at `K_MIN` 3 all five services rotate through one round at a time.
  - Every transaction waits for a successful receipt. Any revert (`AlreadyFinalized`, `RoundAlreadyOpen`, ...) is logged and skipped; `run` also survives a failed tick.
- `apps/relayer/src/run-keeper.ts` + script `pnpm --filter @skeptique/relayer keeper`: loads the deployment manifest, `HEDERA_RPC_URL` and `RELAYER_PRIVATE_KEY` from `.env`; poll via `KEEPER_POLL_MS` (default 15000).
- `kMin()` added to the shared `RoundManager` ABI.
- Harness: `startStack({ round: { K_MIN: 3 } })` forwards to `deployLocal(hre, round)` so a test can run the real `K_MIN` (default local stays 1).
- `e2e/keeper.e2e.test.ts`: lists five services, three critics; keeper finalises the five due rounds once (second tick sends nothing), opens exactly one round, finalises a void round with non-revealing committers and moves on, then drives valid rounds until all five services have a scored round, checking one open round at a time.

## Output tail
- `pnpm e2e -t "keeper"`: 1 passed. `pnpm e2e -t "keeper|void round"`: 2 passed.
- `pnpm --filter @skeptique/relayer test`: 26 passed; `build` (tsc) clean.

## Deviations
- Listing opens round 1 for each service, so the five initial rounds are open together; the one-at-a-time cap applies to rounds the keeper opens.
- The keeper re-reads rounds each tick from a cursor and critics from `CriticRegistered` logs; fine for hackathon scale, not indexed.
- Not run live on Hedera (the repo `.env` lacks newer variables); local stack only.
