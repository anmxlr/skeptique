# Receipt 15: Critic test calls pay via Hedera x402

## What changed
- `packages/x402-client`: `createHederaPayAndCall` (x402 v2 `exact`, HBAR in tinybars, `hedera:testnet`) behind the existing `PayAndCall` interface. `signer` = `{accountId: "0.0.x", privateKey}` (ECDSA). `maxPrice` is checked before signing (own check plus `spendControls.allowedAssets.maxAmountPerPayment`), then `onBeforePay(price, payTo)`; a deny or over-cap price aborts before any payment is created. `settledTxId()` reads `PAYMENT-RESPONSE.transaction`. `createLocalPayAndCall` is untouched.
- `apps/services/common/paywall.ts`: `createPaywall` paywalls `POST /call` through the facilitator (`X402_FACILITATOR_URL`, payTo `SELLER_ACCOUNT_ID`), settles after the handler succeeds and reports the tx id. `startService(..., {paywall})` is opt-in; `paywallFromEnv(price)` returns null without env, so local mode stays free.
- `packages/shared/src/hashscan.ts`: `hashscanTxUrl(txId)`; null for anything that is not `0.0.x@s.n`. The service page (`apps/web/components/service-detail.tsx`) links each `Evidence.x402Txs` entry through it, so links are never typed in.
- Live test: `e2e/critic-pays-x402.live.test.ts`.
