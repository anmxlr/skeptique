# Receipt 16: World Agent Pass critic onboarding, with denied paths

## What changed
- `apps/api/src/world.ts`: `POST /world/rp-context` (signs the IDKit request with `WORLD_SIGNING_KEY` via `@worldcoin/idkit-server`, remembers the nonce) and `POST /world/verify`. The server never trusts the client result: it checks action, environment, an issued and unexpired single-use nonce, and that `signal_hash` equals `hashSignal(critic)`; asks World (`developer.world.org/api/v4/verify/{rp_id}`); normalises the nullifier to bytes32; refuses a nullifier already given to another critic; then signs the voucher `(nullifier, critic, expiry, chainid)` with `ATTESTOR_PRIVATE_KEY`. Every failure is `403 {reason}` with one of `unverified | expired | cancelled | duplicate_human | tampered_payload`; the routes sit in their own Fastify scope so any content type or broken JSON also ends in a 403. Mounted only when `world` deps are given; `apps/api/src/index.ts` builds them from env.
- `apps/web/lib/onboard.ts` + `components/critic-onboarding.tsx` (on the Critics page): start, complete in World App (real IDKit), server validation, then the registration transaction, which is sent only after a 200 with a well-formed voucher. Denied states show a clear alert with the reason. The browser reads only public values (`NEXT_PUBLIC_WORLD_APP_ID`, `NEXT_PUBLIC_WORLD_ENVIRONMENT`, `NEXT_PUBLIC_CRITIC_REGISTRY`, API URL).
- `.env.example`: `WORLD_ENVIRONMENT` plus the three public vars. `packages/harness`: `StackOptions.api` now also accepts `world` (type only).

## Notes and deviations
- No spec/03 edit (frozen). `/world/verify` response `expiry` is a JSON number (voucher expiry set by our attestor), as the note proposes.
- The nullifier and nonce stores are in memory. The contract's `DuplicateNullifier` remains the durable guard; an API restart forgets issued nonces (the person just restarts) and which critic got which voucher. The same critic address may re-fetch a voucher with a fresh proof.
- The signal is the lowercased critic address. Web registration scales `value` by 1e10 on chain 296 (Hedera JSON-RPC weibars); the local chain takes `minStake` as is, matching the seed.
- The page flow with a real wallet and World App was not exercised in a browser here; the logic is covered by the unit and e2e tests and the live API run.
- Full `pnpm e2e` runs every stack at once with a `next build`; under that load the harness and buyer stacks can time out at startup. Both pass when run alone.
