## Deviations / notes for the team
- **Node 20 pins.** Vitest 5 and Hardhat 3 need Node 22+. This machine runs Node 20.20, so the scaffold pins Vitest 3 and Hardhat 2, which run on Node 20, 22 and 24. If the whole team is on Node 22+, upgrading is possible later; it's not needed for the hackathon.
- **TypeScript 5.9, not 7.** TS 7 (native) was the npm default but lacks the JS API that ts-node (Hardhat) and Next.js use.
- **Empty-compile workaround.** `contracts/hardhat.config.ts` creates `artifacts/`, because `hardhat-viem` otherwise prints an ENOENT stack trace when there is nothing to compile. Harmless once 08 adds contracts.
- **Merge note.** `main` has an untracked, empty `Readme.md`. On Windows (case-insensitive) it blocks checking out this branch's `README.md`; delete or move it before merging.
- No spec/03 change.
